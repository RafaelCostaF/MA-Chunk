# Results

Outputs of `ma_chunk.*` and `scripts/run/*` are written here (ignored by git). The raw outputs behind the paper (per-question selections, end-task answers and verdicts, RAGAS scores, CodeCarbon logs; ≈670 MB) are distributed as a separate archive; extract it here or point `MA_CHUNK_RESULTS` to it. Its layout is described in docs/REPRODUCE.md, Section 4.
